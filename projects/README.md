# Projektek

Fokozatosan építhető alkalmazások. A két nyelven azonos problémát oldunk meg, nyelvspecifikus megoldásokkal.

- [Logelemző CLI](01-log-analyzer/README.md) — Fájlkezelés, feldolgozás, CLI-tervezés és tesztelés.
- [Párhuzamos endpoint checker](02-endpoint-checker/README.md) — HTTP, korlátozott concurrency, timeout és cancellation.
- [Job processing API](03-job-processing-api/README.md) — API-tervezés, háttérmunka, állapotkezelés és megbízhatóság.

Minden projekt saját mappát és később önálló futtatási leírást, teszteket, valamint szükség szerint saját függőségkezelést kap. A technológiát az adott mérföldkő előtt választjuk ki.
