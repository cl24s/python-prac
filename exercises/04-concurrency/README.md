# Concurrency – gyakorlatok

Állapot: tervezett; feladatváz.

## Első feladat: bounded-workers

Dolgozz fel feladatokat korlátozott párhuzamossággal; legyen timeout, megszakítás és ellenőrizhető erőforrás-takarítás.

## Kidolgozás előtt rögzítendő

- Konkrét bemenet és elvárt kimenet, példákkal.
- Szélső esetek és hibakezelés.
- Használható eszközök és mérhető elfogadási feltételek.

A konkrét feladat majd a `bounded-workers/` almappába kerül, a [feladatsablon](../TEMPLATE.md) alapján.
