# Hibakezelés és erőforrások – gyakorlatok

Állapot: tervezett; feladatváz.

## Első feladat: safe-file-processing

Tervezz soronkénti fájlfeldolgozót, amely külön kezeli a hibás rekordot és a megnyithatatlan fájlt.

## Kidolgozás előtt rögzítendő

- Konkrét bemenet és elvárt kimenet, példákkal.
- Szélső esetek és hibakezelés.
- Használható eszközök és mérhető elfogadási feltételek.

A konkrét feladat majd a `safe-file-processing/` almappába kerül, a [feladatsablon](../TEMPLATE.md) alapján.
