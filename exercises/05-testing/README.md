# Tesztelés – gyakorlatok

Állapot: tervezett; feladatváz.

## Első feladat: test-a-parser

Írj teszteseteket egy parser normál működésére, üres bemenetre és hibás rekordokra; indokold a teszthatárokat.

## Kidolgozás előtt rögzítendő

- Konkrét bemenet és elvárt kimenet, példákkal.
- Szélső esetek és hibakezelés.
- Használható eszközök és mérhető elfogadási feltételek.

A konkrét feladat majd a `test-a-parser/` almappába kerül, a [feladatsablon](../TEMPLATE.md) alapján.
