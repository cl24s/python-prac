# Teljesítmény – gyakorlatok

Állapot: tervezett; feladatváz.

## Első feladat: streaming-aggregation

Tervezz nagy bemenetet feldolgozó összesítést; mérd a memóriaigényt és az időt két megközelítésnél.

## Kidolgozás előtt rögzítendő

- Konkrét bemenet és elvárt kimenet, példákkal.
- Szélső esetek és hibakezelés.
- Használható eszközök és mérhető elfogadási feltételek.

A konkrét feladat majd a `streaming-aggregation/` almappába kerül, a [feladatsablon](../TEMPLATE.md) alapján.
