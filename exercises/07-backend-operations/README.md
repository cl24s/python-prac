# Backend és üzemeltetés – gyakorlatok

Állapot: tervezett; feladatváz.

## Első feladat: reliable-http-call

Tervezz HTTP-klienst timeouttal és korlátozott retry-val; határozd meg, mely hibáknál és műveleteknél szabad újrapróbálkozni.

## Kidolgozás előtt rögzítendő

- Konkrét bemenet és elvárt kimenet, példákkal.
- Szélső esetek és hibakezelés.
- Használható eszközök és mérhető elfogadási feltételek.

A konkrét feladat majd a `reliable-http-call/` almappába kerül, a [feladatsablon](../TEMPLATE.md) alapján.
